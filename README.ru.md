# 🐬 FlipperZero-BadUSB-Scripts

[English](README.md) · **Русский**

Коллекция BadUSB-скриптов для Flipper Zero, включая полезные утилиты и демонстрации возможностей устройства. Скрипты предназначены для security-тестирования и автоматизации задач.

---

## 📋 Скрипты в репозитории

### 1. **Сбор системной информации и кейлоггер через Telegram**
- **Описание:** Скрипт собирает системную информацию (имя ПК, IP-адреса, данные Wi-Fi, сведения об оборудовании) и записывает нажатия клавиш (кейлоггер). Данные отправляются в Telegram через webhooks.
- **Целевая платформа:** Windows
- **Возможности:**
  - Сбор системной информации.
  - Кейлоггер.
  - Передача данных в Telegram.

## 🚀 Пошаговое руководство

### 1. **Скачайте файл скрипта**
1. Перейдите в папку нужного скрипта (например, `System Info & Keylogger`).
2. Скачайте лежащий внутри PowerShell-скрипт (например, `main_script.txt`).

### 2. **Создайте Telegram-бота**
1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot` и следуйте инструкциям.
3. Получите токен бота (например, `123456789:ABCdefGHIjklMNOpqrstUVWXyz`).
4. Сохраните токен для следующих шагов.

### 3. **Получите ваш Chat ID**
1. Найдите бота в Telegram и начните с ним диалог.
2. Используйте метод API:
   - Откройте ссылку: `https://api.telegram.org/bot<Ваш_Токен>/getUpdates` (замените `<Ваш_Токен>` на токен вашего бота).
   - Найдите поле `chat` и сохраните значение `id` (например, `123456789`).

### 4. **Настройте скрипт**
- Откройте файл `main_script.txt`.
- Замените следующие строки своими данными:
  ```powershell
  $telegramToken = "<TOKEN>"  # Замените <TOKEN> на токен вашего бота
  $chatId = "<CHAT_ID>"       # Замените <CHAT_ID> на ваш Chat ID
  ```
- Сохраните изменения.

### 5. **Загрузите скрипт в Dropbox**
   - Создайте аккаунт или войдите в [Dropbox](https://www.dropbox.com).
   - Загрузите файл скрипта в Dropbox.
   - Получите ссылку для общего доступа к загруженному файлу.

### 6. **Создайте короткую ссылку через Bitly**
   - Перейдите на [Bitly](https://bitly.com) и создайте аккаунт, если его нет.
   - Вставьте ссылку Dropbox и создайте короткую ссылку.
   - Скопируйте короткую ссылку (например, `https://bit.ly/example`).

### 7. **Отредактируйте Ducky-скрипт**
   - В файле `System Info & Keylogger via telegram.txt` замените существующую ссылку `https://bit.ly/example` на вашу новую короткую ссылку.

### 8. **Загрузите Ducky-скрипт на Flipper Zero**
   - Скопируйте файл `.txt` в папку `badusb` на вашем Flipper Zero.
   - Подключите Flipper Zero к целевой системе и запустите скрипт.

---

## ⚠️ Важно

- Используйте эти скрипты **только в законных и этичных целях**.
- Не используйте их для несанкционированного доступа или вредоносных действий.
- Убедитесь, что токен Telegram и Chat ID в скрипте соответствуют вашим настройкам.
- Скрипты перестают работать после закрытия PowerShell или выключения/перезагрузки компьютера.
